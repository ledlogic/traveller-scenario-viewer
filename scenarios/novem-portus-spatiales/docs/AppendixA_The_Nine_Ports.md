## A.1 — WHAT THE PORTS ARE

**A note on the word.** Torvald called the nine pieces *portus*: openings through which a signal passes. In this document a capital-P **Port** always means one of the nine pieces of the build. A starport is always "starport", "the station" or "the field" where confusion is possible.

Each Torvald Build is nine Ports, I to IX. In every build, each Port is one of two kinds:

- **T (Torvald):** her own careful imitation. Works as ordinary code. Does nothing.
- **N (native):** a transcription of the Lattice's own signal. Structured like nothing a person would write.

All nine *headers* carry Torvald's signature, so a casual inspection shows nine matching Ports in each build. The difference is underneath.

When a Port is run it draws a simple line image. Torvald added these as mnemonics. The images differ slightly between T and N versions of the same Port: a door open in one and bricked up in the other, a hand holding a key in the left or the right.

## A.3 — CHECKS

| Task | Check |
|---|---|
| See that a build has nine signed Ports | Average (8+) Electronics (computers) (1D hours, EDU) |
| Tell N from T within one build | Difficult (10+) Electronics (computers) (1D hours, INT) |
| Compare two builds once the method is known | Average (8+) Electronics (computers) (1D hours, INT) |
| Recognise N Ports as a recorded signal | Average (8+) Science (cybernetics) or Science (xenology) (EDU) |
| Spot that Pankow IX is forged, from the code alone | Formidable (14+) Electronics (computers) (1D hours, INT) |
| Spot it with all three grids completed | Difficult (10+): IX is the only N Port whose image is *identical* to the T versions |
| Spot it after reading Kesh's page | Automatic: "I have kept the ninth to myself" |

**Helping:** one assistant with the relevant skill at 1 or better gives DM+1 (task chains, Core Rulebook, Skills and Tasks chapter).
